# 十分钟上手 Markion

这是一份可以边读边改的操作路线。开始前，请按[样例目录](README.md)的说明，将整个 `examples` 文件夹复制到自己的目录。以下操作都在副本中进行。

## 1. 打开文件夹与文档

选择 **文件 → 打开文件夹**，选中复制后的目录，在左侧文件树中打开本文件。打开文件夹用于建立工作目录，不会替换当前正文。需要查找某个文档时，可以在文件树中输入文件名片段进行筛选。

从文件树打开另一份样例，可以在标签页之间切换。使用 **文件 → 打开** 时，会尝试在当前标签中打开；有未保存内容时，请按提示保存或取消。整理笔记时，可以在文件树中创建文件夹、重命名、复制文档，或拖动文件到另一个文件夹。

## 2. 试用四种视图

在视图菜单或界面中的模式切换处，依次体验这些方式，具体名称以当前界面语言为准：

| 模式 | 用途 | 试一试 |
| :--- | :--- | :--- |
| 源码 | 精确修改 Markdown 标记 | 把 `**重点**` 改成 `*重点*` |
| 分栏预览 | 同时观察源码和渲染效果 | 新增一项列表，观察预览 |
| 阅读 | 专心浏览完成的文档 | 使用大纲跳转到下一节 |
| 可视化编辑 | 直接编辑排版后的内容 | 修改标题、勾选任务、调整表格 |

可视化编辑中的公式、图表、HTML 等内容可能以源码块的形式编辑；遇到需要精确修改的标记，可以切回源码模式。模式切换不会把 Markdown 转成另一种文件格式。

## 3. 做一次格式修改

这是普通段落。请选择“普通段落”几个字，用格式菜单或右键提供的格式操作加粗，再撤销和重做。快捷键可以在偏好设置的快捷键页查看，修改过快捷键后以该页为准。

如果已在偏好设置中启用斜杠命令，可以在可视化编辑的空段落中输入 `/`，从列表中选择标题、列表、代码等块格式。需要直接输入 Markdown 标记时，也可以随时切回源码模式。

- [ ] 将本节标题改成“我的第一次编辑”
- [ ] 在此列表中新增一项任务
- [ ] 把其中一项标记为完成
- [ ] 通过左侧大纲跳转到“查找与替换”

## 4. 查找与替换

下面有三处相同的词，可以用来练习：

- 项目代号：练习项目
- 文档名称：练习项目使用记录
- 本次目标：完成练习项目的第一轮整理

打开查找，搜索“练习项目”，尝试上一处、下一处；再打开替换，把它改成“我的笔记”。先看匹配范围，再决定逐项替换或全部替换。需要时可以使用区分大小写和正则表达式选项。

## 5. 保存、专注与恢复

使用 **文件 → 保存** 保存当前副本；“另存为”可以更换文件名或位置。图片练习需要连同 `images` 目录保存，详见[图片与导出指南](05-images-links-export.md)。

在偏好设置中可以调整界面主题、文字大小、自动保存行为；在视图相关设置中体验专注模式和打字机模式。自动保存与恢复快照的行为取决于设置，重要内容仍应主动保存并备份。

## 6. 导出一份可分享的成品

先打开[会议纪要模板](11-meeting-notes.md)，填写一项决策，然后从导出菜单选择所需格式，例如 HTML、PDF、Word 或图片。选择一个自己有写入权限的输出目录，导出后打开结果，核对标题、表格和图片是否完整。

不同导出格式对公式、图表和 HTML 的表现可能不同。保留 `.md` 原稿，导出文件用于交付；不要把导出成功等同于所有复杂排版都已完全一致。
