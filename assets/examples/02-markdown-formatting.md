# Markdown 格式练习

请在复制后的文档中练习。使用分栏预览观察源码与效果，再切换可视化编辑体验直接修改。完成后可删除说明，把保留的段落整理成自己的语法备忘录。[返回目录](README.md)

## 标题与段落

一份长文通常用一级标题作为文档名，用二级、三级标题划分章节。观察左侧大纲如何随标题变化。

### 三级标题：小节

#### 四级标题：补充说明

##### 五级标题：细节

###### 六级标题：附注

这是第一段。空一行可以开始新段落。

这是第二段。这里使用 HTML 换行：<br>这一句从新行继续，但仍属于同一段。

练习：新增一个二级标题，拖动或编辑章节内容，再从大纲中找到它。

## 行内格式

写作时可以使用 *斜体*、**粗体**、***粗斜体***、~~删除线~~、`行内代码`、==高亮==，以及 H~2~O 和 x^2^ 这样的下标、上标。

源码里的转义可以保留标记本身：\*这不是斜体\*，\# 这不是标题。行内代码可以展示语法，例如 `**需要强调的内容**`。

练习：把“需要强调的内容”改成自己的提醒；选中一段文字应用格式，再撤销，观察原文是否恢复。

## 引用与分隔线

> 先记录事实，再写判断，最后给出行动。
>
> 引用中也可以有 **重点** 和列表：
> - 第一条证据
> - 第二条证据

---

分隔线适合分开正文与附录，不宜代替所有章节标题。
