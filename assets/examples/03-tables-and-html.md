# 表格与 HTML 练习

在自己的副本中练习表格编辑。简单数据优先用 Markdown 表格；需要合并单元格时，可以使用 HTML 表格。[返回目录](README.md)

## Markdown 表格：进度与对齐

| 工作项 | 负责人 | 状态 | 预计小时 |
| :--- | :---: | :---: | ---: |
| 收集需求 | 小林 | 已完成 | 2 |
| 整理样例 | 小周 | 进行中 | 4 |
| 验收文档 | 小陈 | 待开始 | 3 |

源码中的 `:---`、`:---:`、`---:` 分别表示左对齐、居中和右对齐。数字列右对齐，便于纵向比较。

练习：

1. 把“整理样例”的状态改为“已完成”。
2. 在可视化编辑中进入一个单元格，尝试表格提供的行列插入、删除和对齐操作。
3. 新增“实际小时”列，填写数字，再撤销一次。
4. 回到源码，检查表头分隔行是否完整。

## 单元格中的行内内容

| 写法 | 效果或说明 |
| :--- | :--- |
| **重要** | 需要强调的结论 |
| `status` | 字段或变量名 |
| [项目计划](13-project-plan.md) | 指向另一份样例 |
| 研发 \| 文档 | 用反斜线转义竖线 |
| 第一行<br>第二行 | 用 HTML 换行 |

练习：把最后一行改成自己的两条简短说明。复杂的嵌套内容不适合普通 Markdown 表格，可考虑拆成正文段落。

## HTML 表格：合并单元格

下面的表格使用 `rowspan` 和 `colspan`。需要调整合并范围时，切到源码编辑 HTML，并检查每行实际占用的列数。

<table>
<tr><th rowspan="2">阶段</th><th colspan="2">交付物</th></tr>
<tr><th>文档</th><th>检查项</th></tr>
<tr><td>准备</td><td>需求摘要</td><td>范围已确认</td></tr>
<tr><td rowspan="2">实施</td><td>操作指南</td><td>步骤可复现</td></tr>
<tr><td>示例文件</td><td>离线可打开</td></tr>
</table>

练习：把“准备”改为“调研”，新增一行独立阶段；保留现有合并单元格，检查预览网格是否对齐。
