# 图片、链接与导出

本页使用随安装包附带的图片，不依赖远程图片服务。请先复制整个样例目录，再练习资源整理。[返回目录](README.md)

## 本地图片与替代文本

![Markion 标志：随样例打包的本地 PNG](images/markion.png "本地图片示例")

在源码中，`images/markion.png` 相对于本 Markdown 文件所在目录。替代文本应描述图片内容，便于图片加载失败时理解上下文。

练习：修改替代文本和图片标题；切到可视化编辑，体验图片提供的尺寸或对齐操作。也可通过插入图片功能选择自己的本地图片，观察资源路径。

## 图片跟着文档走

```text
我的笔记/
  05-images-links-export.md
  images/
    markion.png
```

复制上面的整个文件夹，图片路径仍然有效。如果只移动 Markdown，图片可能丢失。“另存为”用于保存文档内容，不保证把手写相对路径引用的图片一起搬走。

Markion 还可以根据图片资源设置保留、复制、下载或上传图片。需要分享时，先确认接收方是否能访问图片地址。不要在准备离线阅读的文档中只保留远程图片；上传和在线图片服务需要另行配置，本样例不要求使用它们。

## 文档链接与引用式链接

[每日笔记](10-daily-note.md)和[会议纪要](11-meeting-notes.md)使用同目录相对链接。可以从文件树打开目标文档来核对路径。

引用式链接适合多次使用同一目标，例如[项目计划][plan]。在线参考可以写成 [Markion 项目主页](https://github.com/willmove/markion)，离线时跳过即可。

练习：新增一条指向[阅读笔记](15-reading-notes.md)的链接；将项目计划链接的显示文字改成“下一步计划”，保持目标不变。

## 导出前后的核对

| 交付需求 | 可考虑的格式 | 核对重点 |
| :--- | :--- | :--- |
| 继续编辑、版本管理 | Markdown | 原稿和本地资源是否齐全 |
| 网页阅读 | HTML | 样式、图片和链接是否可用 |
| 固定阅读版式 | PDF | 分页、长表格、字体是否合适 |
| 对方继续使用办公软件 | Word | 表格、图片、公式兼容性 |
| 截取文档视觉效果 | PNG / JPEG | 裁切、清晰度和内容是否完整 |

练习路线：保存副本 → 从导出菜单选择一种格式 → 写入自己的目录 → 用对应程序打开结果 → 逐项核对。某些内容在不同导出后端中会有差异，请以实际结果为准。
