# AI Agent

AI 默认关闭。在**偏好设置 → AI Agent**中配置，或按 **Ctrl+Shift+A**（Windows/Linux）/**Cmd+Shift+A**（macOS）。需要自带服务和 API Key，Markion 不附带服务订阅。

## 配置服务

选择 OpenAI、Anthropic、DeepSeek、本地/Ollama 或自定义兼容服务，填写服务支持的模型 ID 及所需密钥。**获取模型**是可选操作，也可直接手填模型 ID。**测试连接**仅发送合成文字和无副作用的工具探测，不附带文档。确认可用后保存配置。

自定义和本地/Ollama 配置在基础设置中直接显示基础 URL 和协议（`responses`、`chat`、`anthropic`）；云端配置的这两项位于高级设置中。高级设置还包括有限的请求限制和写作偏好；写作偏好有独立的保存按钮，切换预设或配置不会被重置。基础 URL 示例为 `https://api.example.com/v1`，不要附加 `/chat/completions`、`/responses` 或 `/messages`。仅回环地址允许 HTTP；拒绝重定向及 URL 中的用户名、密码。

Ollama：启动本地服务并安装要使用的模型，选择本地/Ollama，填写模型 ID。默认地址为 `http://localhost:11434/v1`。本地/自定义服务可以不填密钥。不同模型的能力可能不同；不支持工具仍可文字聊天，工作区工具需要对保存后的端点、协议、模型完成工具能力验证。

密钥使用操作系统安全凭据存储。密钥框留空会保留该配置和端点已有的密钥。安全存储不可用时，可以明确选择**仅本次会话使用密钥**。密钥不写入偏好设置或聊天记录。高级设置可管理删除配置、重置设置后仍保留的密钥引用；**删除密钥**移除对应凭据。切换端点不会借用另一端点的密钥。

## 聊天与写作

AI 面板有独立的多行输入和撤销。Enter 发送，Shift+Enter 换行；中文输入法组词期间按 Enter 不会发送未完成输入。**停止**取消生成。关闭面板后，状态栏仍显示运行状态，可以重新打开并停止或审阅。

空白聊天不包含当前文档。明确添加**选区、全文或文件**，附件标签展示范围及大小，也可发送前移除。附件使用未保存的缓冲区内容；上下文过大时阻止发送，不静默截断。已验证来源按钮仅来自实际附件或工具读取，模型编造的路径不会成为已验证链接。

支持起草、续写、润色、纠正语法、精简、扩写、调整语气、翻译、总结、提纲、提取待办、自定义指令。目标语言和语气独立于界面语言。未选择内容时，需明确选择全文或光标前内容；阅读模式选区只能用于分析。

生成不会直接修改文档。先审阅修改前后，再复制、替换原范围、插入原光标，或新建未保存笔记。未完成结果只能复制或重试，不能应用。替换会验证原文档实例、版本、路径和源码；原文变化或关闭后，结果不会转投其它标签。应用写作结果是独立的一次撤销，不与此前输入合并。持久文件操作使用恢复入口，不使用编辑器撤销。

## 整理文件

通过**授权读取文件夹…**明确选择当前工作区内的文件夹。授权范围可见，只在当前对话和会话有效，不随历史恢复。撤销授权、切换工作区或关闭 AI 会取消工作并使提案失效。

开启**使用工作区工具**后，可有限地列出文件、搜索文件名/文本、读取精确范围，并提出修改文本、新建笔记/文件夹、逐个移动或重命名文件的提案。支持 `.md`、`.markdown`、`.mdown`、`.txt`；拒绝隐藏/受保护目录、疑似密钥文件、二进制文件、路径穿越、危险 Windows 名称、符号链接/目录联接和硬链接歧义。不提供命令行、外部系统工具、发布、Git 修改或永久删除工具。

逐项检查路径、修改前后内容和依赖关系，再选择应用。可编辑目标名称/路径并更新审阅；依赖项不能缺少前置操作。**审阅链接更新**只分析授权范围内的内容，入链修改是可单独选择的提案；移动笔记自身的链接修改出现在其差异中。授权范围外的引用显示为未检查。移动未保存文件需要先保存；打开文档的文本修改通过检查边界进入缓冲区并可撤销，磁盘修改则有持久恢复记录。

操作准备和完成记录保存在工作区外。部分失败会保留已完成项，并标明其余结果；重试不会自动重放已完成项。关闭 AI 会停止尚未开始的操作，已经获准的文件系统步骤会安全完成到可恢复边界。

## 恢复和记录

AI 关闭时，仍可在设置中使用**恢复文件操作**。检查路径后选择恢复、继续已审阅操作，或移除已解决记录。恢复不会覆盖后续编辑、被替换的工作区、冲突目标或非空新建目录。恢复记录独立于设置重置和聊天记录删除；中断或不明确的记录会保留供检查。

默认仅在内存保留对话。可选择本地历史，上限为 20 个对话/8 MiB；仅保存可见消息，不保存原始附件、工具读取载荷、密钥、读取授权和可执行批准。恢复对话需要新上下文。关闭持久保存后回到会话模式，已有记录仍可明确删除。

## 排查与本地测试

- 认证失败：检查该端点的密钥。
- 找不到模型/端点：检查模型 ID、基础 URL 和协议。
- 本地服务不可用：启动模型服务并确认回环端口。
- 不支持模型发现/工具：手填模型 ID，或使用文字聊天。
- 超出上下文限制：移除附件、缩小范围或新建对话。
- 结果失效/文件冲突：保存当前工作并重新生成计划；仍可复制或新建未保存笔记。

可运行 `python scripts/ai-mock-provider.py --port 18114` 进行无需密钥的确定性测试。自定义配置使用 `http://127.0.0.1:18114/v1`、`chat`、`mock-agent`，只添加合成文档。`mock-text` 用于文字模式回退；包含 `slow` 的问题用于停止测试。临时文件夹中的合成文件 `a.md`、`b.md` 可在明确授权后使用 `synthesize`（综合）和 `organize`（整理）指令。
