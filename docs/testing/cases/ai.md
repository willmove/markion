# AI 聊天、审阅与恢复

先读[统一入口](../README.md)和[人工隔离指南](../human-runbook.md)。G组目录位于run/git；其他素材位于run/workspace。每个变体独立建行，外部工具/平台缺失如实记录。

## A01 无密钥配置与工具能力

**优先级：** P1

**前置与素材：** workspace/ai/a.md、b.md；本地 mock（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 独立终端运行 python scripts/ai-mock-provider.py --port 18114。
2. AI 默认关闭时从快捷入口进入设置；自定义 URL http://127.0.0.1:18114/v1，chat，mock-agent，空 key；测试/获取模型/保存启用。
3. 换 mock-text 验证文字模式，恢复 mock-agent 并重验；重启。

**预期：** 测试不附带笔记；草稿保存/启用顺序清楚，能力随配置失效/重验；持久配置保留，session-only 对话和授权不自动恢复。

**变体（逐项建行）：** 自定义/本地；服务未启动；text-only／tools；取消设置草稿。

**证据与收尾：** 配置去敏副本、模型列表和重启截图；无真实云 key、无系统凭据删除。

## A02 输入隔离、流式与停止

**优先级：** P0

**前置与素材：** 01-editing.md，A01 已配置（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 文档保持已保存，AI 输入中文实际组词；Enter 选候选不发送，Shift+Enter 换行，输入框 Undo。
2. 发中文消息和包含 slow 的 follow-up；流式时手动滚动、Stop。
3. 另一次 slow 时关闭面板，通过状态栏重开并停止。

**预期：** 输入/快捷键留在 composer，不改文档；组合 Enter 不误发；停止保留不完整结果且不可 Apply；关闭面板不谎报任务已停止。

**变体（逐项建行）：** 实际IMEs／英文；长多行；窄面板；会话切换保留草稿。

**证据与收尾：** 候选窗、发送时序和正文基线比较；GPUI 组合测试另列。

## A03 显式上下文、预算与来源

**优先级：** P0

**前置与素材：** workspace/ai/a.md、b.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 空白对话发送消息，确认无默认文档附件。
2. 修改 a.md 未保存，分别附选区/全文/文件，检查名称、范围、字节并移除一次。
3. 用低预算/大附件触发超限；打开来源链接，另测缺失/移动来源。

**预期：** 仅显式上下文进入请求；使用dirty缓冲区；超限阻止当前请求、不静默截断；来源只对应真实附件/读取，不能把模型编造路径当验证链接。

**变体（逐项建行）：** 选区/文档/文件；CJK字节；历史预算；原文件被移动/替换。

**证据与收尾：** 附件列表/预算反馈和来源选区；mock正文不用于证明真实云模型效果。

## A04 写作审阅与失效目标

**优先级：** P0

**前置与素材：** workspace/ai/a.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 选 Alpha 发起润色/翻译等预设；未选择时明确选全文或光标前。
2. 结果出来先取消/复制，再分别 Replace、Insert、New note；每次独立新run。
3. 生成后修改/切换/关闭原标签再应用；测试不完整结果。

**预期：** 审阅前无源改动；只应用捕获目标，inactive不转投当前标签；已改或关闭目标拒绝；独立一次Undo恢复；Read无法映射选区只分析。

**变体（逐项建行）：** 全部12写作预设至少可达；翻译语言/语气必填；Source/Visual/Read。

**证据与收尾：** before/after范围、独立expected、Undo比较、拒绝提示；不能以回答文本质量代替目标安全验证。

## A05 授权、文件提案与恢复

**优先级：** P0

**前置与素材：** workspace/ai/ 作为单独打开的工作区（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 新对话只授权 ai 目录，synthesize 检查 a/b 字节来源；organize 生成文件夹与移动提案。
2. 先改目标/依赖后取消，确认磁盘不变；新生成并选择Apply，再审阅 Restore File Actions。
3. 分别恢复、外部新编辑后恢复、关闭AI/清历史/重启后审阅；执行中撤销授权。

**预期：** 未批准不写盘；依赖检查正确；Apply只改审阅范围；恢复不覆盖新内容；完成项不重放；恢复记录独立于对话、AI开关，授权不随历史恢复。

**变体（逐项建行）：** 无授权/撤销；dirty move Save First；collision/部分失败/中断（无法可靠造出写BLOCKED）。

**证据与收尾：** 操作journal、磁盘基线、恢复前后哈希、来源跳转；不在真实笔记目录授权。
