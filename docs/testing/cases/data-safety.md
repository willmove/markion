# 数据安全与文档生命周期

按[统一规则](../README.md)建独立运行目录。下列路径相对于 run/workspace；变体逐行记录。每个编辑动作独立执行、保存核对，再一次 Undo 保存比较基线；失败保留现场，下一分支用新 run。

## D01 新建、保存与另存为

**优先级：** P0

**前置与素材：** 01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 文件 → 新建，输入 QA 中文😀 é 与第二段。
2. 保存到工作区内 中文 空格/新笔记.md；关闭后重开。
3. 另存为 copy.md，独立核对两文件；再编辑副本。

**预期：** 完整 UTF-8 内容符合独立预期；原文件不受副本后续编辑影响；成功保存后路径、标题和 dirty 指示正确。

**变体（逐项建行）：** 已有文件／未命名；Source／Visual；LF／CRLF。

**证据与收尾：** 保存文件、独立 expected、完整字节比较、标题截图。

## D02 保存取消、覆盖确认与不可写错误

**优先级：** P0

**前置与素材：** 01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 输入一处未保存修改，分别取消保存和另存为对话框。
2. 在专用目录选择已有目标，分别取消和确认覆盖。
3. 将测试目标设为当前账户确实不可写，尝试保存，再恢复权限。

**预期：** 取消不改路径或旧文件；失败保留 dirty 文本和先前路径，有可理解反馈；确认覆盖只写指定目标。

**变体（逐项建行）：** 保存／另存为；未命名／已命名；只读文件／不可写目录。

**证据与收尾：** 前后哈希、错误提示和权限设置；管理员账户可写时不能声称测到了失败。

## D03 自动保存设置与多标签写入

**优先级：** P0

**前置与素材：** 01-editing.md、02-structures.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 确认初始配置自动保存关闭，编辑两标签并等待超过设置延迟。
2. 开启自动保存、设置延迟，分别编辑并等待写入。
3. 关闭自动保存再编辑，核对磁盘；重启检查偏好。

**预期：** 关闭时不自动保存正文；开启时各文件内容与对应标签一致；状态反馈正确，无旧内容回写或跨标签覆盖。

**变体（逐项建行）：** 两个文件；快速连续编辑／等待后编辑；正常／D04 外部冲突。

**证据与收尾：** 时间、配置副本、两文件完整比较；恢复测试配置。

## D04 外部修改、删除与冲突选择

**优先级：** P0

**前置与素材：** 01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 打开并编辑但不保存；用外部编辑器将磁盘正文改为 EXTERNAL。
2. 显式保存及自动保存分别触发冲突。
3. 每次新 run，分别选择 Reload、Overwrite、Save a Copy；另测外部删除及仅 touch 时间而字节不变。

**预期：** 普通保存不静默覆盖 EXTERNAL；Reload 使用磁盘正文，Overwrite 仅在明确选择后写当前文本，Save a Copy 保留外部文件；纯 metadata 改动无假冲突。

**变体（逐项建行）：** 修改／删除／只改时间；手动／自动保存；每个选择独立。

**证据与收尾：** 冲突框、各目标与副本内容、前后哈希。

## D05 脏文档离开保护

**优先级：** P0

**前置与素材：** 01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 关闭自动保存，修改到易识别的 UNSAVED 标记。
2. 分别关闭标签、文件 → 新建／打开、切工作区、退出。
3. 对实际出现的离开确认分别选择保存、放弃、取消；若安全打开新标签，核对旧脏标签仍在。

**预期：** 未保存内容不被静默替换；取消保持原标签／内容，放弃是显式选择；保存失败不能当作成功离开。

**变体（逐项建行）：** 命名／未命名；欢迎／普通／图片标签；打开当前标签偏好开／关。

**证据与收尾：** 转场前后截图、磁盘与 dirty 状态；不能要求每条打开路径都必然弹框。

## D06 标签休眠后的历史与选区

**优先级：** P0

**前置与素材：** 01-editing.md、02-structures.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 在 A 文档中部输入 ONLY-A，保留选区并滚动。
2. 切 B 输入 ONLY-B，再切 A；重复至少 10 次。
3. 分别 Undo／Redo，切模式并重开，核对另一个标签。

**预期：** 内容、选区、滚动与各自历史不串标签；缓存休眠不产生编辑；A 的 Undo 不改变 B。

**变体（逐项建行）：** Visual／Source／Split；两个长文件和一个图片标签混合。

**证据与收尾：** 两个文件 expected、一次撤销比较及转场录屏／截图。

## D07 强制中断后的文档恢复

**优先级：** P0

**前置与素材：** 01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 只在本次 PID 中编辑 UNSAVED-RECOVERY；等待并确认隔离 Recovery 目录实际出现快照。
2. 记录快照与磁盘基线，强制结束该 PID；可另在退出后把原磁盘改为 EXTERNAL-NEW。
3. 重启同一 profile，审阅并恢复；保存副本，再正常保存／显式丢弃。

**预期：** 恢复未保存正文且标为 dirty；不覆盖 EXTERNAL-NEW；原路径上下文清楚；成功保存或显式丢弃后对应旧快照退休。

**变体（逐项建行）：** 命名／未命名；磁盘未变／外部变化／路径已删除。

**证据与收尾：** 中断前快照、恢复后源码、原文件哈希、专用 PID 和日志。

## D08 恢复管理器逐项处理与再次中断

**优先级：** P0

**前置与素材：** D07 产生的两个真实快照（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 退出测试进程，在其 Recovery 下新增坏快照 bad.md，内容为 invalid-recovery。
2. 重启，单独恢复第一项，检查第二项和坏项仍保留；分别测试 Restore All／Discard All。
3. 在另一新 run，恢复后未保存立即强制结束，再重启。

**预期：** 坏格式项显示不可读且 Restore All 不删除它；未选择项保留；恢复后再次中断仍能找回；已有同路径干净 session 标签不重复。

**变体（逐项建行）：** 单项／全部；可读／不可读；立即再中断；同路径 session 已恢复。

**证据与收尾：** 快照目录清单、两次启动截图与正文；仅在隔离目录造坏文件。

## D09 UTF-8、行尾与 EOF 保真

**优先级：** P0

**前置与素材：** line-endings/lf.md、crlf.md、no-eof.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 分别打开，四种模式来回切换并保存，比较基线。
2. 只替换唯一文本 hello 为 HELLO，用独立预期比较。
3. 一次 Undo 后保存，与原始基线逐字节比较。

**预期：** 纯切换不修改源；改动局限于目标字节，LF／CRLF 和无末尾换行保持；中文、emoji、组合字符没有拆坏。

**变体（逐项建行）：** 三种行尾；Source／Visual 修改；文件首／中／末。

**证据与收尾：** compare 命令输出和输入输出哈希；不得先规范化换行再比较。

## D10 纯文本与数据文件

**优先级：** P1

**前置与素材：** data/notes.txt、sample.json、sample.yaml、sample.toml（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 从文件树和打开对话框分别打开各文件。
2. 输入、Undo、开启自动保存；尝试所有视图模式动作。
3. 另存为核对默认扩展名，再切回 Markdown 原标签。

**预期：** 数据文件使用源码／代码字体及适用高亮，无 Markdown 预览大纲；纯文本不被格式化；dirty、保存和扩展名正确；Markdown 模式恢复。

**变体（逐项建行）：** 四种文件；重启 session；系统拖入；无效 JSON 仍可编辑。

**证据与收尾：** 文件与菜单截图、保存字节及 session 恢复结果。
