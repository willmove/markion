# 编辑、输入与搜索

按[统一规则](../README.md)建独立运行目录。下列路径相对于 run/workspace；变体逐行记录。每个编辑动作独立执行、保存核对，再一次 Undo 保存比较基线；失败保留现场，下一分支用新 run。

## E01 四模式往返与只读边界

**优先级：** P0

**前置与素材：** 01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 依次选择 Source、Visual Edit、Split Preview、Read，再反向返回。
2. 在每个可编辑模式做一个唯一改动并撤销。
3. Read 下尝试输入、删除和替换，再恢复编辑模式。

**预期：** 非编辑切换不改正文；历史和选区保留；Read 不修改源；Split 两栏及同步滚动没有错误定位。

**变体（逐项建行）：** 长文档／短文档；同步滚动开／关；各模式重启恢复。

**证据与收尾：** 完整基线比较、模式截图和编辑历史观察。

## E02 键鼠选择与导航

**优先级：** P1

**前置与素材：** 01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 双击 hello，三击该段，拖选中英混合文字；连续 Primary+A 两次。
2. 执行词移动／词删除、Shift+Home/End、PageUp/Down 及扩选。
3. 在格式边界、段首、EOF 重复，删除后一次撤销。

**预期：** 选词、段落、整篇范围准确，无隐藏语法边界误删；光标与选择可见；Undo 恢复。

**变体（逐项建行）：** Source／Visual；正向／反向选区；窄窗口折行；macOS Option 词键。

**证据与收尾：** 操作后选区截图和保存比较。

## E03 自动配对与即时输入规则

## E04 空结构与连续 Enter／Backspace

**优先级：** P0

**前置与素材：** 02-structures.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 在标题、首中末列表项和任务项末尾 Enter。
2. 空列表项再次 Enter 退出，再连续 Enter 两次并输入中文。
3. 父列表带子树时 Tab／Shift+Tab，引用中间段转正文，逐次撤销。

**预期：** 光标与新增空行可见；合法缩进保留完整子树；退出列表不吞后续块；引用拆分保持顺序；独立动作一次撤销。

**变体（逐项建行）：** 无序／有序／任务／引用；空标题；LF／CRLF；EOF。

**证据与收尾：** 源码前后比较、光标截图、一次撤销；不沿用旧 P1 的“子树一律拒绝”预期。

## E05 真实 IME 组合、停顿与撤销

**优先级：** P0

**前置与素材：** 01-editing.md、03-tables.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 切系统中文输入法，输入 nihao，保留候选至少 4 秒，再空格／数字选候选提交。
2. 一次 Undo，再 Redo；新组合用 Escape 取消。
3. 滚到视口底部、格式边界、代码和空表格单元格重复，组合时点击／切焦点。

**预期：** 候选窗随光标；提交为完整中文，一次 Undo 恢复组合前文本而非拼音；取消不残留；无 UTF-8 崩溃或跳屏。

**变体（逐项建行）：** Source／Visual；段落／代码／表格；Windows Pinyin；Linux IBus/Fcitx 中韩文；macOS 系统 IME。

**证据与收尾：** 真实候选窗截图／录屏、完整保存比较、崩溃日志；粘贴中文不能满足此项。

## E06 真实剪贴板与富文本粘贴

**优先级：** P0

**前置与素材：** 01-editing.md、clipboard.html（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 在外部浏览器打开 clipboard.html，选择样本正文复制到文档。
2. 从实际 Word 和表格软件分别复制格式段落／矩阵再粘贴；再用纯文本编辑器作为来源。
3. Copy／Cut 局部文字到外部编辑器；每次 Paste／Cut 后一次 Undo。

**预期：** 纯文本原样，富文本转换到受支持 Markdown；只作用选区／光标；外部接收的文本／HTML 正确，整次粘贴可撤销。

**变体（逐项建行）：** Windows CF_HTML／macOS public.html／Linux X11、Wayland；prose／单元格；无 HTML clipboard。

**证据与收尾：** 记录双方软件版本、接收内容、保存比较；仅在应用内自拷贝不足以证明跨应用。

## E07 多块、列表子树与重排分隔

**优先级：** P0

**前置与素材：** 02-structures.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 用 grip、Shift 扩选选择两段并 Copy／Cut／Delete。
2. 拖动 parent subtree 到 last sibling 后；再用键盘上移／下移和菜单移动。
3. 保存对照块顺序，再一次 Undo 保存比较原文件；滚动边缘拖动。

**预期：** 子项和嵌套代码完整跟随；独立段落／引用不合并；无自／后代落点破坏；鼠标、键盘和菜单语义一致。

**变体（逐项建行）：** 多块／完整子树；LF／CRLF／无 EOF 换行；正反向拖动；Shift+click。

**证据与收尾：** 新顺序 expected、撤销后基线比较、实际拖动视频；不支持持键点击的工具记该变体 BLOCKED。

## E08 选区格式与捕获目标

## E12 菜单生命周期、子菜单与焦点

**优先级：** P0

**前置与素材：** 03-tables.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 打开 Row/Column 或 Insert 子菜单，以鼠标悬停、方向键、Enter、Escape 操作。
2. 点击单元格文字／padding／原单元格，随后新建、切换、关闭标签或打开图片。
3. 缩窄窗口，滚至最后可用动作；在链接／图片属性字段输入并取消。

**预期：** 飞出菜单可达且不越界；外部点击和文档转场关闭旧菜单，无崩溃；字段输入不触发正文快捷键；取消无正文更改。

**变体（逐项建行）：** 菜单根／二级；各转场独立；明暗主题；最小支持窗口。

**证据与收尾：** 原生转场录像、stderr、基线比较；复杂过期回调另标自动化层。

## E13 查找替换与过期搜索

**优先级：** P0

**前置与素材：** 06-search.md、large/mixed-1024kb.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 查找 needle，切大小写、正则，测试上一／下一、无匹配及非法正则。
2. 分别替换当前和全部；每次一次 Undo 后比较基线。
3. Read 查找 link-label 和 hidden-destination，尝试 Replace 后切回编辑；大文件搜索过程中输入或换标签。

**预期：** 匹配范围／数量正确；非法正则有反馈不崩溃；Read 只查可见 label，不改源，回编辑后替换状态可恢复；旧查询结果不落到新文档。

**变体（逐项建行）：** Source／Visual／Split／Read；大小写开关；正则捕获替换；密集单行。

**证据与收尾：** 查询/选项截图、expected 与撤销比较、旧结果不串文档记录。
