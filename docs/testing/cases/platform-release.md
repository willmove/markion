# 平台、性能与发布闭环

先读[统一入口](../README.md)和[人工隔离指南](../human-runbook.md)。G组目录位于run/git；其他素材位于run/workspace。每个变体独立建行，外部工具/平台缺失如实记录。

## P01 逐包安装、启动与用户数据保留

**优先级：** P0

**前置与素材：** 实际候选 NSIS/ZIP/DMG/DEB/RPM/AppImage（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 专用测试账户/VM：干净安装或展开对应包，启动并记录实际程序与资源位置。
2. 打开合成笔记、改设置，退出重启；安装上一稳定版本后覆盖候选，核对保留数据。
3. 卸载/删除应用副本，确认个人文档按产品策略保留；macOS另从浏览器下载经Finder首次打开。

**预期：** 每格式可用、架构正确，打包资源可找到；不会借仓库回退掩盖缺包；升级不丢文档/配置；如未公证按实际说明反馈，不宣称已公证。

**变体（逐项建行）：** README矩阵每包；Linux兼容发行版；有/无系统Vulkan；macOS arm64和真实Intel。

**证据与收尾：** 安装日志、包/实际exe哈希、资源清单、首次启动截图、系统安全提示。

## P02 离线样例库与安装资源

**优先级：** P1

**前置与素材：** 安装包内 Examples and Templates（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 断网，从帮助 → 样例与模板定位系统文件管理器目录。
2. 复制整个目录到可写测试位置，再打开文件夹，查看五篇指南、十二模板及PNG。
3. 改一模板保存重开，验证相对图/文档链接；核对安装原件。

**预期：** 实际安装资源完整可离线使用；复制后可编辑，安装原件哈希不变；入口缺资源时报可理解反馈而不崩溃。

**变体（逐项建行）：** 每包；只读安装目录；AppImage临时挂载；中文复制路径。

**证据与收尾：** 包资源验证日志、文件管理器截图、原件/副本哈希；调试payload不是release安装证据。

## P03 偏好、语言、主题与真实缩放

**优先级：** P1

**前置与素材：** 四类文档与AI面板（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 遍历每个内置主题和八种语言（含韩语），改变字体/字号/行距（75–300%）/段距（0–128px）/代码显示/Outline位置/隐藏文件/快捷键。
2. 重启检查持久化；造快捷键冲突，重置偏好；新profile测试缺失及合成错误类型值回退。
3. 在真实缩放与最小支持窗口检查所有设置、长名称、菜单、AI审阅与恢复控制。

**预期：** 设置即时并正确持久化；重置有明确范围，不删除文档/恢复记录；无截断到无法操作，快捷键反馈正确；不改变源。

**变体（逐项建行）：** 明/暗 × 代表长短语言 × 100/150/200%或macOS实际档位；小窗口/重启。

**证据与收尾：** 环境缩放截图、去敏配置、全部关键按钮可达记录；不修改日常全局DPI。

## P04 窗口边角、首帧与输入可见性

**优先级：** P1

**前置与素材：** 04-rendering.md、large/mixed-1024kb.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 测试关闭/最小化/最大化/还原/全屏，四边四角hover并拖动resize。
2. 拖侧栏/分栏/Outline分隔线，在文档底部连续单行+Enter。
3. 开关focus/typewriter，观察输入后的立即帧及settled帧；在实际Wayland compositor复测。

**预期：** 按钮/边角命中正确；内容不被阴影边框遮住；光标与前文始终可见，无第一次缺caret或交替隐藏；拖动不与菜单混淆。

**变体（逐项建行）：** Windows/macOS/X11/Wayland；窗口/最大化/fullscreen；typewriter开/关；HiDPI。

**证据与收尾：** 真实hover/drag录屏、首次帧截图、compositor/GPU驱动版本；截图外观不能代替拖动通过。

## P05 真实连续输入与内存观察

**优先级：** P1

**前置与素材：** large/ 下四个mixed文件、dense-line.md、05-images.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. release候选依次打开100/300/600/1024 KiB，分别在首中末连续输入、IME、滚动和查找。
2. 独立按键长测至少1000次，分段保存，与独立累积expected核对，再Undo/Redo。
3. 多轮大文档/图多标签切换、关闭，返回小文档；采集打开/输入分布和进程内存。

**预期：** 保存无丢重键；交互无新冻结/视口错误；记录全部样本、P50/P95/max和回落趋势；不把模型benchmark当键盘到GPU延迟。

**变体（逐项建行）：** 四大小；密集单行/全局引用/图多另列；无编译并行负载；同机旧版对照。

**证据与收尾：** 原始时序、CPU/GPU/构建与fixture哈希、完整内容比较、RSS/Private与模型归因；绝对毫秒数不是跨机器硬门槛。

## P06 真实上一版本升级与失败回退

**优先级：** P0

**前置与素材：** 专用账户/VM中的上一稳定版 + 最终签名更新元数据（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 打标签前检查可用更新UI/脏文档保护；没有受信候选源时signed升级保持NOT_RUN。
2. 最终正式元数据可用后：Windows NSIS、运行中的Linux AppImage从上一版本执行更新，记录签名验证、安装/替换/重启版本。
3. dirty拒绝；再测断网/坏清单/下载/签名/启动失败和浏览器fallback（需既有可控测试源，无此能力记BLOCKED）。
4. 核对默认自动下载、关闭自动下载、到期后台检查、已验证包的“稍后”与菜单重开；自动下载不等于安装授权，安装前再次检查 dirty。

**预期：** 默认可后台下载并验证，关闭自动下载时等待用户动作；安装始终需要明确确认且dirty拒绝；“稍后”保留本会话已就绪包；未验证payload不执行；失败现安装仍可用；macOS/DEB/RPM走正确手动下载，不声称自替换。

**变体（逐项建行）：** Windows/AppImage成功；每种失败；自动下载开/关；后台到期/手动检查；Later/重开/dirty确认；macOS/DEB/RPM/不带公钥构建fallback。

**证据与收尾：** 旧新版本/hash、签名/manifest、安装日志和重开内容；禁止改生产latest或伪造新公开tag只为造场景。

**优先级：** P0

**前置与素材：** 标签工作流产物和当前版本验收报告（见[素材说明](../fixtures/README.md)）。

**步骤：**

**变体（逐项建行）：** GitHub/OSS；所有平台包；候选/最终构建映射；缺环境必须披露。

**证据与收尾：** 工作流与Release链接、下载哈希/签名、最终smoke记录；现workflow会自动发布，此项限制完成声明，不声称新增人工发布暂停。
