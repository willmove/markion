# 表格、结构渲染与图片

遵循[统一入口](../README.md)和[隔离指南](../human-runbook.md)。素材路径相对于 run/workspace；逐个变体新建结果行，破坏性分支使用新 run。

## R01 表格光标、空格与列导航

**优先级：** P1

**前置与素材：** 03-tables.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 点击空表头、连续空行和长折行单元格文字及 padding。
2. 用 Up/Down 穿过表头、正文空行，Shift 扩选；边界交接到相邻块。
3. 点击第二张表，核对仍在正确行列。

**预期：** 光标可见，上下保持逻辑列、不停在 Markdown delimiter；空单元格点击不插入文本，跨表格不串归属。

**变体（逐项建行）：** 三列／不齐行；Source 行尾 LF／CRLF；窄窗口折行。

**证据与收尾：** 点击位置／光标截图、无编辑时完整字节比较。

## R02 表格换行、遍历与末格加行

**优先级：** P0

**前置与素材：** 03-tables.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 单元格中间 Shift+Enter 输入第二行。
2. Enter、Tab、Shift+Tab 分别遍历；末格 Tab 新增正文行。
3. 保存检查源码，逐个 Undo／Redo。

**预期：** Shift+Enter 为单元格内硬换行，不拆成新表；普通 Enter／Tab 导航正常；末格只加一行；每次编辑可一次撤销，周边字节不变。

**变体（逐项建行）：** 空格／选区替换；中文/emoji；表头／末格；literal <br> 在代码中不当硬换行。

**证据与收尾：** 换行与加行 expected、单步 Undo 比较、caret 截图。

## R03 矩形、行列选择与矩阵剪贴板

**优先级：** P0

**前置与素材：** 03-tables.md、clipboard.html（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 跨单元格拖选／Shift+click，分别用行列 grip 选择。
2. 复制到实际表格软件核对 TSV／HTML；从外部表格复制 2×2 粘贴。
3. 清空矩形，保存；Undo 并核对视口和源码。

**预期：** 只改变选区内单元格；矩阵方向和内容正确；清空保留结构；清空／Undo 视口稳定，矩阵粘贴作为一次编辑撤销。

**变体（逐项建行）：** 矩形／整行／整列；反向选区；空与不足列；外部 Excel/WPS/LibreOffice 记录版本。

**证据与收尾：** 接收端矩阵、源码 expected、清空前后视口截图；应用内复制另记。

## R04 完整行列工具与列宽

**优先级：** P0

**前置与素材：** 03-tables.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 光标放在第二表，右键第一表中间格。
2. 逐个执行 Row/Column 子菜单当前所有可用项：前后插入、删除、复制、移动、对齐等；每项后 Undo。
3. 拖列宽／列顺序，保存重开；在表头、首末边界验证禁用保护。

**预期：** 操作右键目标；另一个表和周边源字节保持；禁用项不执行；持久列宽／对齐重开保持，结构动作一次撤销。

**变体（逐项建行）：** 记录实际菜单完整目录；7 个行／10 个列命令如仍适用逐项建行；首／中／末／表头。

**证据与收尾：** 每个菜单动作独立 expected、Undo 比较、持久宽度截图；不盲用历史命令数量。

## R05 代码正文、语言与折叠

**优先级：** P1

**前置与素材：** 04-rendering.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 编辑普通围栏和缩进代码，Enter／Paste 后保存。
2. 修改语言芯片、取消、折叠／展开并从搜索进入折叠正文。
3. 滚动长代码行，切到其他标签再返回，点击 Copy。

**预期：** 保留围栏、缩进和正文；未闭合围栏仍可编辑；折叠不改源，进入正文会展开；Copy 位置和背景受栏宽约束。

**变体（逐项建行）：** 围栏／缩进／未闭合；明暗主题；行号／换行开关；小窗口。

**证据与收尾：** 源码与剪贴板比较、折叠／切标签截图、Undo。

## R06 公式与异步图表

**优先级：** P1

**前置与素材：** 04-rendering.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 编辑行内、块公式和 Mermaid，观察完成渲染。
2. 输入确定错误表达式，审阅可编辑错误状态，取消／修正。
3. 渲染未完切标签、改源或撤销，再返回。

**预期：** Ready/Pending/Error 均可理解且不丢源；定界符保留；旧任务不把旧图贴到新文档；错误不冻结 UI。

**变体（逐项建行）：** 正确／错误；重复相同／不同源；CJK/emoji 组合输入；Source/Visual/Split/Read。

**证据与收尾：** 渲染图与源码、日志、输入/取消/Undo 记录。

## R07 前言、TOC、脚注、锚点和 HTML

**优先级：** P1

**前置与素材：** 04-rendering.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 折叠/展开 YAML，编辑后 Undo；检查标题、正文、列表和 HTML 表格。
2. 点击 TOC、中文／重复标题和显式 ID 锚点；脚注 hover 及 Primary+click。
3. 在 HTML、实体、转义和未知标签旁输入；开关 Keep inline syntax hidden。

**预期：** 纯显示／跳转不改源；标题定位准确；脚注预览有来源；已支持实体/HTML 显示正确，未知或畸形保守保留；不把 GFM pipe table 当合并表格。

**变体（逐项建行）：** 四模式；不匹配锚点／脚注；正确／畸形 YAML；稳定行内开关。

**证据与收尾：** 不编辑时基线比较、导航目标与渲染截图；对照已支持范围。

## R08 图片对象、属性与源保真

**优先级：** P0

**前置与素材：** 05-images.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 分别聚焦本地、混排、重复 URL、引用式、data URI 和损坏图片。
2. 对有精确控件的图片修改目标／alt/title、尺寸和对齐，取消一次再确认；拖尺寸后 Undo。
3. 大 data URI 图片加载失败／切标签时继续输入和滚动。

**预期：** 只改目标 occurrence；属性取消不写源；引用不能误改所有引用；失效资源有反馈不冻结；当前图片对象不因 hover/选中暴露大段隐藏源码。

**变体（逐项建行）：** block／inline／reference／HTML img／畸形多行；明暗／HiDPI；合法控件与保守回退分开。

**证据与收尾：** 图片前后 expected、Undo 比较、宽度/错误图；不要求已移除的旧图片源码 toggle。
