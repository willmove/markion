# 工作区与文件入口

遵循[统一入口](../README.md)和[隔离指南](../human-runbook.md)。素材路径相对于 run/workspace；逐个变体新建结果行，破坏性分支使用新 run。

## W01 文件树层级、筛选与隐藏

**优先级：** P1

**前置与素材：** tree/、data/（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 打开 workspace，展开深层目录和空目录，滚动大量文件。
2. 搜索名称、清空，折叠后重开；开关隐藏文件。
3. 检查 .hidden.md、target、node_modules 和 .git 等排除目录。

**预期：** 逐级展开且空目录可见；滚动条／滚轮可达；清空筛选恢复；hidden 偏好即时生效，始终排除噪声目录仍隐藏；大树不冻结。

**变体（逐项建行）：** 隐藏开/关；窗口缩窄；侧栏拖宽；重启。

**证据与收尾：** 筛选前后截图和设置；不要把显示数量当成未扫描全部条目的证明。

## W02 文件创建、改名、移动、复制和删除

**优先级：** P0

**前置与素材：** tree/、01-editing.md（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 在树中新建文件/文件夹，F2 或菜单中文重命名；输入同名和无效名。
2. 将文件／目录拖到新父目录，执行 Duplicate，再删除非空测试目录并分别取消/确认。
3. 对已打开的干净／dirty 文件重复，核对路径和磁盘。

**预期：** 操作仅在目标；同名不覆盖；取消不删；完整复制且使用可用名称，Duplicate 复制磁盘内容而非未保存缓冲区；打开标签与路径按操作一致，dirty 内容不静默丢失。

**变体（逐项建行）：** 文件／含子目录文件夹；中文/空格；目的权限失败；侧栏隐藏下标签改名入口。

**证据与收尾：** 文件清单、源/复制文件哈希、确认框和标签状态；下一变体新 run。

## W03 外部文件变化与旧监听

**优先级：** P0

**前置与素材：** 01-editing.md、tree/（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 外部创建、重命名、删除可见文件；观察树自动更新。
2. 打开并编辑一文件，外部另改/删它，保持未保存内容。
3. 切另一个工作区后在旧工作区操作文件。

**预期：** 树正确更新且不重置无关展开/滚动；dirty 缓冲区保留；远程删除的原文可恢复且自动保存不悄悄重建旧路径；旧监听不污染新根。

**变体（逐项建行）：** 本地外部变化／G03 pull 删除和重命名；隐藏目录变化。

**证据与收尾：** 两目录清单、当前标签内容和日志；遇冲突参见 D04。

## W04 打开入口与当前标签偏好

**优先级：** P1

**前置与素材：** 01-editing.md、data/、images/checker.png（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 文件对话框、树点击、Primary+click、最近文件、系统拖放分别打开受支持文件。
2. 开关“当前标签打开”偏好，重复；打开已经打开的路径。
3. 拖多种文件和不支持类型，观察最终焦点。

**预期：** 安全复用当前标签或开新标签符合偏好；脏文档保留；重复路径聚焦唯一已有标签；数据/图片类型正确，失败有反馈。

**变体（逐项建行）：** 欢迎／干净／dirty／图片当前标签；单/多文件；新标签显式入口。

**证据与收尾：** 每入口和偏好各行记录；启动参数仅测候选已实现的形式，不把尚未实现 CLI 提案作支持。

## W05 标签溢出与长名称

**优先级：** P1

**前置与素材：** tree/large/（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 连续在新标签打开至少 20 个文件，包含长中文名。
2. 在条上滚轮到首尾并关闭；快捷键切到屏幕外标签。
3. 放大窗口让溢出消失，hover 查看完整路径，再创建新标签。

**预期：** 所有标签可达；激活项自动露出；关闭和 dirty 标记不被截掉；新建按钮固定；去掉溢出后滚动位置合法。

**变体（逐项建行）：** 最小窗口／放大；dirty 长标题；鼠标／触控板（可用时）。

**证据与收尾：** 首尾标签、tooltip、关闭/新建按钮截图。

## W06 只读图片标签

**优先级：** P1

**前置与素材：** images/checker.png（见[素材说明](../fixtures/README.md)）。

**步骤：**

1. 打开图片，调整窗口并切主题。
2. 尝试文字编辑、格式、表格和旧上下文动作。
3. 在图片/Markdown/JSON 之间切换，保存 Markdown 后返回。

**预期：** 图片适配显示、无编辑 dirty；不可用命令禁用或安全无效；旧菜单不渲染错误类型；其他标签内容和模式正常。

**变体（逐项建行）：** PNG／可用 JPEG/SVG 额外样本；损坏图片；长路径。

**证据与收尾：** 图片哈希不变、菜单及跨标签截图。
