# Codex／Agent 实机执行指南

与人工使用相同的[用例和发布标准](README.md)，按[人工指南](human-runbook.md)固定构建、准备素材及隔离。Agent 执行完整验收的授权，不等于授权发布版本、使用真实云账户或修改日常数据。

## 执行顺序

1. 读取仓库 AGENTS 和相关计算机控制 skill。发现当前可用的原生 app／输入接口；GUI 操作按工具文档进行。只读源码或 Rust 测试无法证明原生用例通过。
2. 先盘点目标平台、可见会话、OS/IME、浏览器／Office、安装包、权限和可用手势。把环境缺口写入报告，不先宣称“全量测试通过”。
3. 建立新 run，保留用户现有进程。记录自己启动的 PID、程序／包哈希及截图中窗口身份；核对隔离设置实际写入位置。
4. 每次只执行一个编号的一个变体。真实输入后观察 UI 完成，保存并等待磁盘达到完整预期再断言；工具返回“已点击／已输入”不代表应用已处理。
5. 保存原始输出、实际截图、完整文件比较。含中文候选选择、拖动、Shift+click、系统对话框的步骤用真实 OS 事件；接口不支持时记 BLOCKED，继续独立可执行项。
6. 失败保留现场并追加缺陷；本轮验收不自动修产品行为。修复需要遵守 OpenSpec 并记录新构建身份；重跑相关项及核心数据安全回归。
7. 更新报告逐项结果和发布决策；只退出本次启动的测试进程。最后确认日常文档／配置未被使用，保留运行目录供审阅。

## 证据边界

| 执行方式 | 能证明什么 | 不能替代什么 |
| --- | --- | --- |
| OS_INPUT／HUMAN | 当前平台真实鼠标键盘、候选窗、对话框和实际接收软件结果 | 未操作的环境／分支 |
| CALLBACK_REPLAY | 原生窗口 paint、应用回调、部分系统剪贴板调用 | OS 键鼠路由、真实候选选择 |
| GPUI_TEST | 模拟布局、事件、选区／输入合约 | 实际 DPI、窗口系统、跨应用互操作 |
| CLI_CHECK | 构建、字节、资源、签名和自动化契约 | 原生用户流程或实际 Office 排版 |

粘贴“你好”不算 Pinyin 组词；直接写文件不算 UI 保存；程序化调用菜单处理器不算鼠标命中；截图非空不算编辑通过；DOCX 是合法 ZIP 不算 Word 排版通过；打印对话框出现不算 PDF 已保存。无法独立触发的过期回调防御项可引用自动化证据，原生转场用例仍单独执行。

Windows 回放可单独运行 `pwsh.exe -File scripts/Invoke-FluentEditingSmoke.ps1`，标记 CALLBACK_REPLAY。它有自己的隔离目录和输出，不应覆盖当前 OS_INPUT 记录。Pandoc/网络 ignored 项逐个确认前置条件和实际产物；有些测试缺工具会提前返回，退出 0 本身不足以计入实测。

## 可直接交给 Agent 的任务

```text
在本仓库按 docs/testing/README.md 与 codex-runbook.md，对指定候选安装包执行所有适用的发版前验收。
固定提交/dirty 差异、包与程序 SHA-256、资源身份及环境版本；先建全新 run，再启动隔离候选实例。
运行自动化门禁；逐项展开平台、模式、输入法、包格式和失败/取消分支，填 results.csv。
使用真实系统输入完成原生用例，关键编辑保存后比较完整源码并验证一次 Undo。
工具不支持的手势或缺失环境写 BLOCKED/SKIP，不用 GPUI、回调回放、历史记录或截图代替原生 PASS。
只使用合成文档、本地 Git remote、无密钥 AI mock；不发布版本，不使用真实付费服务/账号，不改用户现有进程和配置。
发现缺陷保留现场与最小复现，不自动混入修复；汇总通过/失败/缺环境/未执行和当前是否满足发布条件。
```

执行前明确目标候选包和环境；包路径缺失可先做源码与素材预检，原生组保持 NOT_RUN/BLOCKED。针对旧版本升级的真实安装操作只在专用测试账户／VM 执行，不在当前用户安装上推断授权。需要维护者例外时提供具体待审项与证据，不能因执行超时自动豁免。
