## Why

## What Changes

- Refresh README capabilities, package formats, limitations, editing interactions, and performance evidence; synchronize the standalone Chinese edition and localized status summaries.
- Add a dated project-status entry point and link historical P0/P1 reports to the completed P2/P3 and Windows input verification.
- Reconcile the Visual Edit coverage contract with implemented structured selection, subtree operations, table matrices, folding, and local derivation.
- Prepare synchronized v0.5.3 package metadata and bilingual notes, then follow the canonical release process through verified publication.

Non-goals: no new application behavior, no broad archival of unrelated changes, no unverified manual-test claims, and no replacement of public release tags.
